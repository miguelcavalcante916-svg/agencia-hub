# Logos dos clientes

Biblioteca rápida de logos de clientes para uso em marquee, social proof
e seção "clientes" do site. Prioridade: SVG > PNG transparente.

Se o mesmo logo já existir dentro de `../clients/[slug]/`, não duplique o
arquivo físico — referencie a origem. Se precisar duplicar por
simplicidade do frontend, documente aqui e no `ASSET_INVENTORY.md`.
