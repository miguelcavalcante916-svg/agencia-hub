# Showreel

Apenas takes candidatos ao showreel da agência. Nomeie como `take-01.mp4`,
`take-02.mp4`, etc. Não misturar logos, prints, arquivos de projeto ou
músicas aqui. Se souber de qual cliente veio cada take, registre em
`ASSET_INVENTORY.md`.

Para popular esta pasta: obter os arquivos de vídeo originais (do editor,
do HD de produção, ou baixados do Instagram com autorização) e adicioná-
los aqui com nomenclatura `take-NN.mp4`, registrando a origem/cliente no
inventário.
