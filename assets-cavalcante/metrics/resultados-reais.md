## Nota de auditoria (2026-09-13)

Nenhuma métrica verificada foi encontrada no repositório `agencia-hub`.
O README do projeto indica que dados de tráfego pago (Meta/Google/TikTok),
leads e financeiro vivem dentro dos módulos do AgênciaHub (app), não em
arquivo versionado — portanto não puderam ser auditados a partir do
código-fonte. Para preencher esta página com dados reais, é necessário
extrair os números diretamente do app AgênciaHub (`/app`) ou dos painéis
de anúncio de cada cliente, com print ou export como fonte.
